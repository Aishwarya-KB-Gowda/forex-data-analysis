# 📊 Forex Data Analysis Using Python  

This project performs **Forex Data Analysis** using **Python**, where we analyze historical forex price data, calculate price changes & volatility, and identify the most volatile trading day. The results are stored in a structured CSV file for further analysis.  

---

## 🚀 Features  
✔ Reads forex price data from a CSV file  
✔ Calculates **Price Change** (`Close - Open`)  
✔ Computes **Volatility** (`High - Low`)  
✔ Finds the **most volatile trading day**  
✔ Sorts the data by **volatility (highest to lowest)**  
✔ Stores everything in a **single structured CSV file**  

---

## 🛠 Technologies Used  
- **Python** 🐍  
- **CSV Handling** (`csv` module)  
- **Data Processing & Sorting**  

---

## 📂 Project Files  
- `forex_prices.csv` → Input file with forex data  
- `forex_analysis.csv` → Output file with processed data  
- `forex_analysis.py` → Python script for analysis
